## Findings, ranked

1. ~~Camera permission modal at first login~~ **CORRECTED:** this is the
   cookie/ads **consent banner** (Consent Mode v2 — legitimate and required).
   Real (mild) finding: it overlays the welcome empty-state CTA at first login;
   consider showing it after first interaction or below the fold. Severity: LOW.
2. **Time pickers default to 00:00** (S/M) — logging an evening shift means
   spinning from midnight to 18:30. Add "now"/"last hour" quick-chips or
   default the end time to now when opening the form.
3. **Silent dead tap on บันทึกรอบ** (S) — first save click produced no toast,
   no error, no close; identical retry succeeded. Could not reproduce root
   cause (automation artifact not excluded). Recommend: button disabled+spinner
   during save, guaranteed error toast on any validation failure.
4. **i18n flash on first paint** (S) — dashboard labels render in English
   ("Net revenue — Today") for the first moments after login before Thai
   applies. Apply saved language before first dashboard paint.
5. **No landing page at `/`** (M) — new visitors and ad clicks land directly on
   a login wall. Pairs with growth-audit quick-win #5: a lightweight landing
   (value prop + screenshots + LINE login button) would serve AdSense traffic
   and orientation.
6. **375px pass outstanding** — HANDOFF's own checklist says test mobile
   responsive; automation couldn't resize. Do this before soft launch.

## Strengths worth protecting

- Revenue-first form ordering with thumb-sized chip selectors (provider/type).
- Dashboard insight cards that *explain* zeros ("เพิ่มระยะทางหรือความกินน้ำมัน")
  instead of showing dead stats — rare and good.
- +100%/delta badge, provider breakdown, best-day, trend chart: real analytical
  depth without clutter.
- LINE-green login button, Thai-first copy quality in all sampled strings.
